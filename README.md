# 📦 Supply Chain Analytics Dashboard

## 📌 Project Overview

This project analyzes supply chain performance using Python, SQL concepts, and Power BI. The dashboard provides insights into revenue, products sold, shipping costs, supplier performance, inventory, and logistics.

---

## 🛠 Tools Used

- Python
- Pandas
- NumPy
- Power BI
- Git & GitHub

---

## 📊 Dashboard Insights

- Total Revenue
- Products Sold
- Total Shipping Cost
- Average Lead Time
- Revenue by Product Type
- Revenue by Supplier
- Shipping Cost by Carrier
- Stock Levels by Product Type

---

## 🎯 Key Findings

- Revenue varies across product categories.
- Supplier performance impacts total revenue.
- Shipping costs differ by carrier.
- Inventory levels vary across product types.
- Lead time influences operational efficiency.
